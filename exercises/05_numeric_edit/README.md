# 05 數字編輯 ★★

主題：數字編輯、`PIC ZZZ9.99`、前導零抑制、`DISPLAY`

## 學習目標

完成這一題後，你會：

- 知道「數字編輯欄位」只改變**顯示的樣子**，不改變數值。
- 讀得懂、也寫得出 `Z`、`9`、`*`、`.` 組成的編輯 PICTURE。
- 根據要顯示的最大數值，替編輯欄位留足整數位數。

## 這題要做什麼

要修改的檔案：`Edit.cbl`（不要改 `EditTest.cbl`）

| 段落 | 完成後應該達成 |
| --- | --- |
| `MAKE-PRICE` | 12.50 印成 `  12.50`：前導零換成空白，不是星號 |
| `MAKE-FEE` | 0.50 印成 `   0.50`：個位數的 0 要留著，其餘前導零變空白 |
| `MAKE-LINE` | 1250.00 完整印出，不能被截掉高位 |
| `MAKE-BIG` | 99999.99 完整印出，不能被截掉高位 |
| `SHOW-RECEIPT` | 已經寫好，不用改 |

數值經過編輯欄位再搬回來，必須和原本一樣。畫面輸出要和 `expected.txt` 一致：

```text
PRICE=[  12.50]
FEE=[   0.50]
LINE=[ 1250.00]
BIG=[99999.99]
```

規則：段落名稱不要改。

## 觀念講解

### 1. 編輯欄位是「排版用」的欄位

一般數字欄位 `PIC 9(4)V99` 存的是數值；編輯欄位（PICTURE 裡出現 `Z`、`*`、`.`、`,`、`+`、`-`、`CR`、`DB`…）存的是**排好版、準備印出來的文字**。

```cobol
01  WS-QTY      PIC 9(4).
01  WS-QTY-ED   PIC Z,ZZ9.

MOVE 3071 TO WS-QTY
MOVE WS-QTY TO WS-QTY-ED
DISPLAY "[" WS-QTY-ED "]"          *> [3,071]
```

### 2. 常用的編輯符號

以數值 `7.5` 放進不同 PICTURE 為例：

| PICTURE | 顯示 | 說明 |
| --- | --- | --- |
| `99.99` | `07.50` | `9`：一定印數字，前導零也印 |
| `Z9.99` | ` 7.50` | `Z`：前導零換成**空白** |
| `*9.99` | `*7.50` | `*`：前導零換成**星號**（支票防竄改常用） |
| `ZZ.99` | ` 7.50` | 整數部分為 0 時，`Z` 會連個位都變空白 |

`.` 是**真的**小數點字元，會佔一個位置；和 `V` 不一樣。

### 3. 位數不夠也會截斷

編輯欄位的整數部分每一位都要對應一個 `Z` 或 `9`。位數不夠時，和一般數字欄位一樣會**丟掉高位**，而且不會報錯：

```cobol
01  WS-SCORE-ED  PIC Z9.
MOVE 128 TO WS-SCORE-ED            *> 印出 28
```

### 4. 「個位數要留 9」

想讓 0.50 印成 `0.50` 而不是 ` .50`，最右邊的整數位要用 `9`，其他前導位用 `Z`。

## 常見錯誤

- **用 `*` 取代 `Z`**：兩者都會抑制前導零，但 `*` 印星號、`Z` 印空白。
- **全部用 `9`**：前導零會原樣印出來。
- **整數位數算少一位**：1250 有四位整數，編輯欄位就要至少四個 `Z`／`9`。
- **以為括號長度不重要**：`expected.txt` 會逐字比對，包括方括號裡的空白數量。
- **拿編輯欄位直接做運算**：編輯欄位是給人看的；要計算請用沒有編輯的數字欄位。

## 操作步驟

1. 在專案根目錄執行 `.\coblings.cmd run 05_numeric_edit`（Linux／macOS：`./coblings.sh run 05_numeric_edit`），開始監看這一題。
2. 用編輯器打開本資料夾的 `Edit.cbl`，照「這題要做什麼」修改。**不要改 `EditTest.cbl`**，它是這一題的驗收標準。
3. 存檔後系統會自動檢查：
   - **解析錯誤**：訊息裡有檔名和行號，照著修正語法。
   - **期望／實際不符**：看斷言的標籤，找出是哪個段落的結果不對。
   - **全部通過**：自動跳到下一題。
4. 卡關時執行 `.\coblings.cmd hint 05_numeric_edit` 看提示。
5. 改亂了想重來，執行 `.\coblings.cmd reset 05_numeric_edit` 還原成原題（你改過的版本會備份到 `.coblings/backup/`）。
